# Local project data

This folder is intentionally empty in GitHub. Add your own local files before using the app:

- RFP documents can be uploaded through the interface.
- Knowledge-base documents belong in `knowledge_base/past_proposals/`, `knowledge_base/product_docs/`, or `knowledge_base/case_studies/`.

These documents, the generated JSON output, and the local ChromaDB database are excluded from Git to avoid publishing confidential material.
